# Музыкальный плеер с визуализацией

Учебный проект Левушкина Никиты Денисовича, группа 541.
Преподаватель: Кривоносова Н.В.

Настольное приложение C# / WPF / NAudio для Windows. В комплекте пять оригинальных
демонстрационных WAV-композиций. Плеер также открывает папки с пользовательскими MP3/WAV.

## Запуск

Для готовой Windows x64-сборки распакуйте архив целиком и запустите `MusicPlayer.exe`.
Папка `audio` должна оставаться рядом. Установка .NET для этой сборки не нужна.

Для сборки из исходников нужен .NET 10 SDK:

```sh
dotnet run --project src/MusicPlayer
```

Запуск WPF возможен только в Windows. На macOS/Linux доступны тесты ядра и
кросс-компиляция с `EnableWindowsTargeting`; они не заменяют проверку звука в Windows.

## Возможности

- плейлист с выбором трека и запуском по двойному щелчку;
- воспроизведение, пауза с сохранением позиции, остановка;
- предыдущий/следующий трек и автоматический переход после окончания;
- перемотка, текущая позиция и длительность;
- громкость от 0 до 100 %;
- 32 полосы спектра по реальным PCM-сэмплам, FFT и оконной функции Hann;
- плавное затухание визуализации на паузе;
- сообщение о повреждённом файле, пустой папке или недоступном устройстве;
- освобождение старого аудиопотока при смене трека и закрытии окна.

Визуализация не использует случайные значения. Аудиопоток заполняет буфер,
а UI-таймер рассчитывает спектр. Запись в элементы WPF из аудиопотока не выполняется.

## Сборка и тесты

```sh
dotnet build src/MusicPlayer -c Release
dotnet run --project tests/MusicPlayer.Tests -c Release
dotnet publish src/MusicPlayer -c Release -r win-x64 --self-contained true -o artifacts/windows
```

В GitHub Actions ядро проверяется на Linux и Windows. Отдельно собирается
самостоятельная Windows-версия с пятью WAV-файлами. Её можно скачать из Artifacts.

## Структура

`MusicPlayer.Core`: плейлист, работа с диапазонами времени/громкости, анализатор спектра.
`MusicPlayer`: WPF-окно и `AudioPlayer`, управляющий NAudio. `tests`: исполняемый
набор автоматических проверок без дополнительных тестовых библиотек.

## Демонстрационные аудиофайлы

В `audio` лежат пять стереофайлов WAV, по 18 секунд. Это синтезированные мелодии,
а не записи коммерческих исполнителей. Их можно воспроизвести и использовать
для проверки спектра. Лицензия CC0 указана в `audio/LICENSE.txt`.
Генератор воспроизводит файлы побайтно детерминированно:

```sh
python3 scripts/generate_demo_audio.py
```

## Проверка на защите

1. Включить первый трек, нажать паузу и продолжить.
2. Перемотать в середину и проверить позицию.
3. Установить громкость 0 %, затем вернуть её.
4. Сменить трек и дождаться автоматического перехода.
5. Открыть пустую папку и показать понятное сообщение.
6. Добавить повреждённый WAV, убедиться, что он не закрывает приложение.
